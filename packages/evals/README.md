# @lgtmoose/evals

Runs the review pipeline (the one behind `lgtmoose review --dry-run`) on fixtures and scores what it would post: recall, false-positive rate, severity accuracy, cost and time.

The guide is [docs/evals.md](../../docs/evals.md): the fixture format, scores, running it, the provider matrix, private fixtures and CI. The fixtures themselves are listed in [fixtures/README.md](fixtures/README.md).
