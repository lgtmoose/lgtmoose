Learn from a repository's review history. A bootstrap, asked for on the dashboard's new "Learn from history" page (with write access) or with `lgtmoose learnings bootstrap --repo owner/name` (AWS), reads the review comments that people with write access left on the repository's last merged PRs (200 by default), and the bootstrapper, a fast-tier model in the sandbox with no GitHub token and no checkout, distils them into candidate learnings. Each candidate must cite two distinct comments, pass the prompt-injection detector and the write policy, and not duplicate an existing learning; it's stored as pending by `lgtmoose`, with links to its comments, and is used only once someone with write access approves it (one at a time, or with Approve all). Lint and format configs and CODEOWNERS become learnings too, with no model. The reconciler starts requested bootstraps on the repository's installation; their batches run on the review workflow, capped by `learnings.bootstrapMaxCostUsd` (5 USD by default) and counted in the spend ledger under the monthly caps. Adds migration 0019 (`learning_bootstraps`, `learning_bootstrap_items`; the spend ledger's run ID no longer references `review_runs`).
